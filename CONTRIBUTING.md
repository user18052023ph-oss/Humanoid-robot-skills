# Contributing to Humanoid Robot Skills

We welcome developers, robotics enthusiasts and researchers who want to help build useful skills for humanoid robots.

## How you can contribute

You can:

- Pick an existing Issue
- Propose a new robot skill
- Improve the simulation
- Write Python code
- Work on AI or Computer Vision
- Work on robotics and ROS 2
- Improve documentation
- Test and review contributions

## Getting started

1. Look through the open Issues.
2. Choose a task that matches your skills.
3. Comment on the Issue that you would like to work on.
4. Fork the repository or create a branch.
5. Implement your contribution.
6. Submit a Pull Request.

## Founding contributors

We are looking for a small group of committed developers to help build the project from the beginning.

Potential profit-sharing arrangements for core contributors will be discussed separately and documented in a written agreement.

## Code quality

Please keep contributions:

- Simple
- Modular
- Well documented
- Easy to test
- Easy to extend

We are building this project together.
